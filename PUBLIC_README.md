# Craftable Spawners

A Minecraft **Java Edition 26.3** data pack. Craft mob spawners from mob drops. No mods and no commands required.

## Installation

1. Download the zip.
2. Put it in your world's `datapacks` folder. Leave it zipped. On a server, use that world's `datapacks` folder.
3. Enter the world, or run `/reload`.
4. Run `/datapack list` and confirm the pack is enabled.

## How to use it

**Condense.** Put 9 of the same item in a crafting table to get 1 Condensed item. There is no recipe to turn a Condensed item back into those 9.

**Craft a spawner.** Every spawner recipe has Iron Bars in the center, surrounded by Condensed items. The recipes are listed below.

**Move a spawner.** Mine it with Silk Touch. The dropped spawner keeps its mob. Placing it restores that mob, including for players who are not operators.

The result updates as you craft. A spawner recipe shows a preview, then becomes the real spawner. If the grid has the wrong items, such as plain bones in a spawner recipe, the craft is undone and every ingredient is returned.

A Crafter can condense plain items. Do not put Condensed items in a Crafter. It treats them as plain items, and the extra value is lost. A Crafter also cannot craft spawners. Use a crafting table for those.

Any goat horn works for the goat spawner. Horns do not need a particular instrument.

## Operator commands

These are optional. Players do not need them to craft.

```
/function craftable_spawners:give {mob:"zombie",amount:1}
/function craftable_spawners:give_item {item:"condensed_bone",amount:8}
```

`mob` is the mob id, such as `zombie` or `cave_spider`. `item` is `condensed_` plus the item id, such as `condensed_bone`.

## Removing the pack

Run `/function craftable_spawners:uninstall`, then disable the pack. The id matches the zip name:

```
/datapack disable "file/craftable_spawners-2.0.0"
```
